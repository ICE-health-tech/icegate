TrueDepth and face-related data — response for App Store Review
================================================================
(App: ICE Gate)

Version: 3.2.1


1. Does the app use the TrueDepth API?
---------------------------------------
No. The app does not call Apple’s TrueDepth API and does not use ARKit’s
face-tracking configuration (ARFaceTrackingConfiguration) or any API that
provides a face depth map, 3D face mesh, or facial expression data to the
app. The app does not use ARFaceAnchor, TrueDepth depth data streams, or
other TrueDepth-only face analysis APIs.


2. What is used that might be confused with “face” features?
-------------------------------------------------------------
A) Face ID (device unlock / sign-in)
   The app may request Face ID only through the system LocalAuthentication /
   biometric login flow, as described in NSFaceIDUsageDescription in Info.plist
   (“We use Face ID to allow you to securely log into your account.”).

   That flow uses the device’s secure enclave and system UI; the app does not
   receive TrueDepth face maps, 3D face data, or Apple’s face analysis output.
   The app only receives success or failure from the system for biometric
   login, consistent with standard usage.

B) ARKit (optional health / food features)
   In specific screens, the app uses ARKit with world tracking (and related
   scene understanding) to support food measurement / 3D scanning in the
   user’s environment — not face-based AR. This is not the TrueDepth “face”
   pipeline for identity or biometrics.


3. Purposes of camera / AR / biometric access
----------------------------------------------
- Face ID / biometrics: Optional login or unlock on device; the app does not
  collect face imagery or depth maps as application data.
- ARKit (world tracking): Optional measurement / scanning for health-related
  UI (e.g. food size); no facial recognition; no TrueDepth face data collection.
- Camera (where declared): Photos for features such as food logging, not for
  creating or storing a biometric face template by the app.


4. Third parties and storage
-----------------------------
The app does not send TrueDepth-derived face geometry, face depth data, or
facial recognition templates to our servers or to advertising/analytics
partners because those data are not collected by the app.

Normal account data (e.g. sign-in with email or third-party identity
providers) is governed by our privacy policy and the backend providers we
disclose there; that is separate from TrueDepth face data, which we do not
collect.
